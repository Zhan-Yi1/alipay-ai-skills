# AXML 标签合规

检查 skill 目录下的 AXML 模板中是否使用了支付宝小程序 SKILL 不支持的基础组件、属性或事件。

支持列表见 `references/supported-tag.md`。

## 输入

- skill 目录下的所有 AXML 文件 (文件扩展为 .axml)
- 主 agent 传递的 alipay-skills-static-eval 根目录下的 `references/supported-tag.md`

## 评测方法

### 1. 读取支持列表

读取 `references/supported-tag.md`，获取可用组件清单及各组件的特殊约束。

### 2. 扫描模板

搜索 skill 目录下所有 AXML 文件，提取标签名、属性和事件绑定。

**基础组件**：与 `references/supported-tag.md` 逐一比对，检查属性、事件是否符合约束。

**自定义组件**（如 `<order-card />`）：不受支持列表限制。可通过命名习惯（kebab-case 多词组件名）和 `.json` 的 `usingComponents` 来判断。不用解析引用链，确认路径存在即可。

**虚拟组件**（`<block>`）：不受限制。

### 3. 比对

将提取的标签、属性、事件与支持列表比对。虚拟组件不受限制。自定义组件需确认对应路径的文件存在。

以下情况视为缺陷：

- 使用了不在支持列表中的基础组件标签
- 支持的标签使用了禁用的属性（见支持列表中各组件约束）
- 使用了不支持的事件类型
- 自定义组件路径不存在

## 输出

```

### 问题
- [缺陷] [问题简述]
  - 位置：[文件:行号]
  - 原文：[代码片段]
  - 影响：[简述]
  - 建议：[替换方案]
```

无问题则一句话：「未发现 AXML 标签合规问题。」
